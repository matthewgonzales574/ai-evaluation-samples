## About This Repository

This repository contains anonymized, illustrative samples of the structured evaluation rationale writing I perform as part of AI data annotation work.

These samples demonstrate my approach to:
- Evaluating AI-generated responses for **factual accuracy** and **logical soundness**
- Identifying **reasoning gaps, unstated assumptions, and implicit biases**
- Writing **clear, evidence-based rationales** explaining evaluation decisions
- Applying **multi-step rubrics** consistently and with analytical precision
